# Changelog

## 0.3.0 (2026-08-19)

* Add transactional, restartable out-of-core FFT2/IFFT2 for c8 and c16
* Add pass progress callbacks, cooperative cancellation, and memory-budgeted transpose tiles
* Validate NPY dtype, shape and length while preserving the input file and atomically replacing output

## 0.2.0 (2023-08-29)

* Add c8 and c16 versions of functions
* update some dependencies
