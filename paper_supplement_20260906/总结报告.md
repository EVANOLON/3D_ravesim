## 1. M1:off 模式(直接球面波)对照 — 发现参考实现自身缺陷

### 1a 薄板真空归一化诊断(C10 板,16384²,source-0)

`01_M1_direct_spherical_validation/data/m1a_thin_vacuum/` + 板数据(第一批 02 目录)。

| 模式 | 真空场(均值归一) | 说明 |
|---|---|---|
| fson / cbbpm(Fresnel 缩放) | **1.000–1.001(std 1.7e-4)** | 均匀 ✓ |
| fsoff(off,直接球面) | **min 0.24, max 1.74(std 4.0e-2)** | 中央衍射簇 + 大尺度起伏 ✗ |

真空归一化后对比度(contrast=I板/I真空)L2:
- fson−cbbpm:**5.7e-5**(不变);
- fsoff−fson:**4.04e-2 → 1.66e-2**(去掉照明约定差后仍有 1.7%)。

### 1b 缩小视场三腿对照(2048²,dx=200nm,FOV 410µm ≥ detector 200µm;10µm C 板,M=4)

腿:fastwave CB-BPM / fastwave off / big-wave CPU off(独立实现)。
数据:`data/m1b_legs/*.npy`;配置:`configs/m1b_*.yaml`。

| 对比 | 相对 L2 | 最大 |d| |
|---|---:|---:|
| fastwave CB-BPM vs fastwave off | 1.46e-1 | 2.97 |
| fastwave CB-BPM vs big-wave off | 1.53e-1 | 2.98 |
| **fastwave off vs big-wave off(两个独立"直接球面波")** | **5.4e-2** | 3.77 |

### 1c 真空探针(判定伪影性质)

`data/m1b_vacuum/`:fastwave off 真空(2048² 与 4096²)与 big-wave off 真空。

1. **物理预期**:点源→4m 探测器真空强度 ∝1/r²,±100µm 内变化 <1e-10 → 应为平场;
2. **实测**:两引擎 off 真空均在轴心附近有 0.2–3.8× 的振荡(中心行 0.4→2.6),角上低至 0.22;振荡空间尺度 ~±20µm ≈ 菲涅尔区 √(λz)≈22µm;
3. **分辨率无关**:dx=200nm 与 100nm 伪影逐点一致(min 0.414/0.416,max 3.56/3.54)→ 排除网格采样/点源像素化;
4. **机制**:有限窗口截断球面波传播的边界衍射(窗口 ~19 个菲涅尔区,截断扰动传回视场);大窗口探针(8192²)被 Nyquist 校验拒绝(源→样品段需 dx≤76nm)——印证 off 模式对载波采样的敏感性与审稿提示一致;
5. **结论**:off 模式当前真空传播偏离精确解,不能直接充当 CB-BPM 的"精确参考";CB-BPM 与 off 的 5–15% 差异包含此参考缺陷。

### 1d 论文处理建议

- 引擎正确性主干:**1a 薄物极限(fson≈cbbpm 至 5.7e-5,第一批)+ 同模式 CPU 交叉验证(L2=8.9e-5)**;
- off 模式对照作为"已量化的局限/后续工作"(含本表),或补解析 Rayleigh–Sommerfeld 基准后再报。

图:`figures/m1b_reduced_fov_cross_engine.png`;数值:`m1a_analysis_numbers.txt`。
