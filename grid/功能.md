# grid_generation.py 函数清单

## 2D 基础形状
| 函数 | 说明 |
|------|------|
| `circle(radius, scale_x, scale_z)` | 生成实心圆盘，内部材料 1，外部 0 |
| `non_circle(radius, scale_x, scale_z)` | 生成反相圆盘，内部材料 0，外部 1 |
| `square(lenx, lenz, scale_x, scale_z, id)` | 生成填充指定 id 的矩形 |
| `square1(lenx, lenz, scale_x, scale_z, id)` | 生成填充指定 id 的矩形（使用 round 取整） |
| `hollowcircle(radius1, radius2, scale_x, scale_z)` | 生成空心圆环，环形区域材料 1 |

## 2D 复合形状
| 函数 | 说明 |
|------|------|
| `double_square(lenx1, lenx2, lenz, scale_x, scale_z)` | 两个矩形水平拼接 |
| `double_ring(radius1, radius2, radius3, scale_x, scale_z)` | 双环结构，材料值 1/2/3/0 |
| `triple_ring(radius1, radius2, radius3, radius4, scale_x, scale_z)` | 三环结构，材料值 1/2/3/0 |
| `double_ring_d(radius1, radius2, radius3, scale_x, scale_z, d1, d2, d3)` | 双环密度版，环带填充自定义值 |
| `square_d(lenx, lenz, scale_x, scale_z, density)` | 矩形密度版，填充自定义值 |
| `five_line(resolution)` | 五线分辨率测试图案 |

## 2D 缺陷操作
| 函数 | 说明 |
|------|------|
| `defect_generation(arr, scale_x, scale_z, px, pz, radiusd)` | 在现有网格中插入圆形缺陷（材料 1） |
| `defect_generation_d(arr, scale_x, scale_z, px, pz, radiusd, density)` | 在现有网格中插入圆形缺陷（自定义值） |

## 3D 形状
| 函数 | 说明 |
|------|------|
| `sphere(radius, scale_x, scale_y, scale_z)` | 生成实心球体，内部材料 1，外部 0 |
| `hollow_sphere(radius1, radius2, scale_x, scale_y, scale_z)` | 生成空心球壳，壳层材料 1 |
| `hollow_sphere_with_void(radius1, radius2, sx, sy, sz, void_n, void_pos, void_r)` | 生成空心球壳并挖去指定空洞 |
| `add_voids(arr, void_positions, void_radius, scale_x, scale_y, scale_z)` | 在现有 3D 网格中挖去多个球形空洞 |

## 辅助函数
| 函数 | 说明 |
|------|------|
| `normalize_void_positions(void_positions)` | 统一 void 位置参数格式为列表 |

## 多层结构
| 函数 | 说明 |
|------|------|
| `resolution_generation_04(resolution)` | 04 版分辨率测试多层膜结构 |
| `resolution_generation_05B(resolution)` | 05B 版分辨率测试多层膜结构 |
| `stair2(depth1)` | 2 级阶梯结构 |
| `stair(n, depth)` | n 级阶梯结构 |
